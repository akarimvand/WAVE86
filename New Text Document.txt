مشکل جدید دیتابیس پیدا شده است.

در جدول roles ستون permissions دچار Double/Multiple JSON Encoding شده است.

نمونه مشکل:

به جای:

[
 "user.create",
 "invoice.manage"
]

مقدار ذخیره شده شبیه:

\"\\\"\\\\\\\"...

است.

وظیفه:

1- ابتدا بررسی کن آیا واقعاً تمام رکوردهای roles مشکل دارند یا فقط بعضی رکوردها.

2- مسیر ایجاد این مشکل را پیدا کن:
- seed files
- migrations
- role sync
- backend services

مشخص کن چند بار JSON.stringify روی permissions انجام شده است.

3- قبل از اصلاح Backup بگیر.

4- یک Migration امن ایجاد کن که:
- permissions را Decode مرحله‌ای کند
- تا رسیدن به Array واقعی ادامه دهد
- دوباره فقط یک بار JSON.stringify کند
- داده‌ها حذف نشوند

5- بعد از اصلاح تست کن:

SELECT permissions FROM roles

و مطمئن شو خروجی:

JSON Array معتبر باشد.

6- تمام کدهایی که permissions را ذخیره می‌کنند بررسی کن تا دوباره این مشکل ایجاد نشود.

در پایان گزارش بده:
- تعداد رکوردهای خراب
- علت اصلی
- Migration ایجاد شده
- تست‌های انجام شده
