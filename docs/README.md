## خلاصه یک‌نگاهی

- **نوع سیستم:** Full-stack وب اپلیکیشن مدیریت باشگاه ورزشی (React SPA + Express API + MySQL)
- **الگوی داده:** State-محور — کلاینت کل State را در حافظه نگه می‌دارد و با سرور «همگام کامل» می‌کند (Full-State Sync)
- **احراز هویت:** JWT با انقضای ۳۰ روز + RBAC شش‌نقشی (`super_admin`, `admin`, `secretary`, `coach`, `accountant`, `athlete`)
- **حجم کد:** بک‌اند ~۲۲۰۰ خط TS در ۱۸ فایل | فرانت‌اند ~۱۲٬۰۰۰ خط TSX/TS در ۵۵+ فایل
- **سلامت بیلد:** `vite build` ✅ موفق | `tsc --noEmit` ✅ بدون خطا
